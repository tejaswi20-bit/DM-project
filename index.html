Method

Why a spanning tree gives the cheapest way to connect every building.

Graph model

Each building is a vertex. Each possible cable route between two buildings is an edge, weighted by its cost. A network that connects all buildings with no redundant loop is a spanning tree with V − 1 edges; the cheapest one is the minimum spanning tree.

Kruskal’s algorithm

Sort all links by cost. Take them from cheapest to dearest, accepting a link only if it joins two buildings not yet connected (checked with union-find); otherwise it would form a cycle and is rejected. Stop after V − 1 links. Running time is O(E log E).

Prim’s algorithm

Start from one building. Repeatedly add the cheapest link that connects a building already in the tree to one outside it, until every building is included. With a simple scan this is O(V²), which suits dense graphs such as a campus where every pair of buildings is a candidate.

Notes on this tool

Both algorithms are run on the same graph and must give the same total cost (shown on the Cable plan page as a check). If blocked links leave some buildings unreachable, the result is a minimum spanning forest, and the tool tells you which parts are disconnected. The cost model is the simple one set on the planner page; real projects add terrain, permits and equipment costs.
